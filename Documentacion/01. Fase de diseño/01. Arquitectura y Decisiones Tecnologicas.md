
En este documento encontrarás las decisiones tecnológicas y de la arquitectura del proyecto que se han tomado inicialmente, para que se entiendan las bases de la implementación de este.

## Resumen del Proyecto

**UGR AlhambaIA** nace con el objetivo de integrar un modelo de Inteligencia Artificial de Código abierto Open Source y Open Weights mediante una interfaz de texto conversacional para la Universidad de Granada (UGR).

El sistema está diseñado para funcionar de manera similar a otras plataformas ya existentes de Modelos de IA generativos como ChatGPT, Gemini etc. Esta garantiza una personalización y control dentro del contexto de uso de tecnologías libres en la universidad, donde tendremos sistemas de cuentas de usuario, persistencia de sesiones y un historial de conversaciones interactivo.

---

## 1. Backend y Base de Datos

* **Framework principal:** `Django`.

  * El motivo principal de elección de este framework es que al estar los ecosistemas de IA (como Hugging Face) construidos predominantemente en Python, Django ofrece una integración nativa usando el mismo lenguaje base.
  
* **Base de Datos:** `PostgreSQL`.

  * Para una aplicación de chat conversacional, se requiere almacenar usuarios, sesiones y un alto volumen de mensajes de forma estructurada. PostgreSQL es el estándar para bases de datos relacionales por su escalabilidad, seguridad y fiabilidad en producción.

---

## 2. Frontend y Comunicación en Tiempo Real

* **Tecnología de interfaz:** Sistema de plantillas de Django + "Django Channels".

  * En un chat de IA tradicional, esperar a que el modelo genere toda la respuesta antes de mostrarla produce una mala experiencia de usuario. "Django Channels" implementa *WebSockets*, lo que permite mantener un túnel de comunicación abierto entre el servidor y el navegador. Esto es estrictamente necesario para lograr el efecto *streaming*: ver cómo la IA escribe palabra por palabra en tiempo real sin recargar la página.

---

## 3. Modelo de Inteligencia Artificial

* **Modelo seleccionado:** `Qwen 2.5` (7B). 

	**Filosofía y Licencia:** A diferencia de otros modelos, Qwen 2.5 se distribuye bajo la licencia **Apache 2.0**, lo que lo define como **Software Libre 100%**. Esto permite su uso, modificación y distribución sin las restricciones comerciales de los modelos "Open Weights" de grandes corporaciones tecnológicas. 
	**Justificación técnica de la elección:**
	 1. En pruebas comparativas, demostró una capacidad crítica para resolver acertijos lógico-temporales donde otros modelos (como Llama 3 o Mistral) fallaron. 
	 2. Es capaz de seguir restricciones de formato estrictas (como generar exclusivamente código o JSON.
	 3.  Presenta una excelente comprensión del español y una latencia de respuesta optimizada para ejecución en hardware local (Self-hosting).

## 4. Identidad, Seguridad y Estilo Visual

* **System Prompt (Límites de la IA):** El modelo operará bajo un contexto estricto e invisible para el usuario. Tendrá la directriz de mantener un tono educado, políticamente correcto y académico. Tendrá prohibido generar información sensible o interna de la UGR (aunque tampoco debería de tener acceso a ella).

* **Estilo Visual:** Se busca un diseño moderno, fluido y de alto contraste inspirado en el estilo de la siguiente página web: https://besthorrorscenes.com/ .La paleta de colores estará dominada por el **blanco y el rojo vivo**, para ir a juego con los colores corporativos de la Universidad de Granada.
